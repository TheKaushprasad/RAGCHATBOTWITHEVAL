What does the swiss cheese capability model mean?
LLMs can be very strong in some domains (like solving complex physics problems) but can fail randomly at simple tasks such as counting, spelling, or simple number comparisons. Models have “holes” in their capabilities, so tasks they might fail at need specialized tools [1].

How Queryva works

From your documents to trusted answers, in a few simple steps.

  1. 1

    Ingestion

    Load PDF, Word, Markdown or text files, keep their structure, split into ~350-token chunks, embed and store in Supabase.

  2. 2

    Retrieve

    Find the 5 most relevant chunks using semantic search, with optional hybrid keyword search.

  3. 3

    Stay on topic

    If the best match is weak, answer “I don’t know” without calling the LLM.

  4. 4

    Generate with citations

    Use only the retrieved passages to write the answer, and cite every claim.

  5. 5

    Trusted answer

    Get a clear answer with clickable citations, or “I don’t know” if the documents don’t contain it.

Features

Built for answers you can check, not answers you have to trust.

Clickable citations

Every claim links to the passage it came from, with the file name and page, so you can verify it in a click.

“I don’t know” by design

Two guards: an off-topic filter before the LLM, and a prompt rule that refuses when the passages don’t contain the answer.

Upload your own files

Drop in PDF, Word, Markdown or text files. Headings, lists and tables are kept so citations point to the right section.

Private uploads

Your uploads are searchable only from your browser, never by other visitors, and are deleted automatically after 24 hours.

Hybrid search

Semantic search finds meaning, keyword search finds exact terms, and Reciprocal Rank Fusion combines both rankings.

Evaluated end to end

Correctness, faithfulness and context recall are measured on a golden dataset, and each failure is traced to retrieval or generation.

FAQ

What can I ask Queryva right now?

The live demo is indexed on a set of AI Product Management notes covering LLM fundamentals, prompt and context engineering, RAG, MCP, machine learning and agentic AI. You can also upload your own file and ask about it.

Which file types can I upload?

PDF, Word (.docx), Markdown and plain text, up to 4 MB each and 5 files at a time. Scanned PDFs without a text layer aren’t supported, because there is no OCR.

Who can see the documents I upload?

Only you. Uploads are tied to a random ID stored in your browser, so search returns the shared demo notes plus your own files, never anyone else’s. Uploads are deleted after 24 hours.

What happens when the answer isn’t in my documents?

Queryva says “I don’t know” instead of guessing. Clearly off-topic questions are filtered out before the LLM is called; for on-topic questions the documents don’t cover, the model is instructed to refuse rather than use outside knowledge.

Can Queryva still be wrong?

Yes. It can retrieve the wrong passage or give an incomplete answer, which is why every claim is cited so you can check it. On the 100-question golden dataset, 88% of answers matched the expected answer and none contained claims unsupported by the passages.

Which AI models does it use?

OpenAI text-embedding-3-small for search and gpt-4.1-mini for answers. Google Gemini is supported as an alternative provider.
